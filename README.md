# Vertical Bar Companion

Vertical Bar Companion is a desktop app that connects a NetSuite account to CrossCheck. You sign in
to CrossCheck and to NetSuite inside the app, choose the account and role, and it sets up the
connection and the CrossCheck SuiteApp for you.

This repository holds the app's releases only.

## Download

Get the latest version from [Releases](https://github.com/verticalbarHQ/verticalbar-companion/releases/latest):

| System | File |
| --- | --- |
| macOS (Apple silicon) | `VerticalBarCompanion-mac-arm64.dmg` |
| macOS (Intel) | `VerticalBarCompanion-mac-x64.dmg` |
| Windows 10/11 (x64) | `VerticalBarCompanion-win-x64-setup.exe` |

The app tells you when a newer version is available.

## First launch

The installers are not code-signed yet, so the operating system asks before the first launch.

- **macOS:** open the app once with Control-click → **Open**, then confirm **Open**.
- **Windows:** if SmartScreen appears, choose **More info** → **Run anyway**.
